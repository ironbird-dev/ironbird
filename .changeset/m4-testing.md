New package. `@ironbird/testing` runs ironbird from Vitest or Jest against a headless definition in process, with no daemon. `createTestTarget` serves the CLI's `DaemonClient` interface over a headless target. `runScenario(file, { headless, env?, artifacts? })` runs one scenario file and returns its `ScenarioResult`, with `passed: false` rather than a throw when a step fails. `modelTest` generates random sequences of commands, fake controls, and clock advances with fast-check 4, checks named invariants against the whole state after every step, shrinks a failure to a minimal sequence, throws `INVARIANT_FAILED` with the seed, path, and steps, and writes the steps as a replayable `.trace.yaml` scenario file; when a step the app rejected changed state anyway, the trace is still written but `traceReplayable` is `false` and its description says which steps. Payloads come from each command's JSON Schema through `arbitraryFromSchema`, which refuses keywords it can't honor rather than guessing; pass a `payload` override for those. For `oneOf`, branches of listable values (`const`, `enum`, boolean, null) contribute exactly their values that match one branch. ESM and CommonJS builds, Node 22 or later, `zod` 4 as a peer.
