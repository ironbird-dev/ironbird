# M5 Doctor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `ironbird doctor` (R20): a daemon-free CLI command that runs eight checks (Node, config, headless load, ports, `.gitignore`, package versions, `simctl`, `adb`), prints `{ checks: [{ id, ok, required, detail, fix? }] }`, and exits 0 when every required check passes and 1 otherwise.

**Architecture:** A new `packages/cli/src/doctor/` folder. `environment.ts` holds every probe of the machine (HTTP `status` probe, port bind test, host tools, installed `package.json` files) behind one injectable `DoctorEnvironment` interface. `checks.ts` holds the six environment-driven checks as functions of that interface, so each is unit tested with fakes. `project.ts` holds the two checks that read the project itself (config and headless entry), which bundle into a fresh temporary directory under `.ironbird/`, never `.ironbird/cache`. `run.ts` runs the checks in order, turns an unexpected throw into a failed check, and computes the exit code; `cli/program.ts` registers the command and loads `run.ts` on demand.

**Tech Stack:** TypeScript 6 strict, Node 22+ (`fetch`, `AbortSignal.timeout`, `node:net`), esbuild 0.25 through the existing `loadTypeScriptModule`, Zod 4 through the existing config schema, commander 15, Vitest 5 `unit` project, Changesets 3 (`@changesets/config` 4.0.0).

**Spec:** [docs/superpowers/specs/2026-10-04-m5-adapters-and-0.1-design.md](../specs/2026-10-04-m5-adapters-and-0.1-design.md). This plan implements D6, §6, the doctor row of §7 ("cli.md: ... `doctor` (§6's output)"), and the Doctor row of §11. Cross-plan names: `.superpowers/sdd/m5-contract.md` (not committed), "Plan 3: doctor". Plan 3 is independent of plans 1, 2, 4, and 5; it runs after plans 2 and 1 on the same branch, so `program.ts` and `docs/cli.md` already carry their `snapshot` and `watch` changes when this plan starts.

**Prerequisites:** Branch `m5-adapters-and-0.1`. Run `pnpm install && pnpm build` once before Task 1: the CLI's tests import `@ironbird/core` from its `dist`, and Task 4's fixture imports it the way an app does. No task changes another package, so no rebuild is needed between tasks; Task 5 builds the CLI once for its smoke run.

## Review Focus

The inputs the spec implies but no spec test names, most likely to bite a user first. Each has a test in the task that owns the code.

1. **A fresh clone whose `.gitignore` already lists `.ironbird/` but which has no `.ironbird/` directory yet.** It must pass. `git check-ignore .ironbird` (no slash) says "not ignored" in exactly this case, so the check asks with a trailing slash; pinned against real git (Task 3, "passes a fresh clone ...").
2. **A headless entry with bare imports such as `@ironbird/core`.** `doctor` must report what `ironbird serve` would: its bundle has to sit where bare imports resolve from the app's `node_modules`, not in `os.tmpdir()`. Pinned with a committed fixture that imports `@ironbird/core` (Task 4, "bundles where the daemon would ...").
3. **`doctor` run while a daemon is running.** It must not touch the daemon's `.ironbird/cache` or `daemon.json`, must leave no directory of its own behind, and must not leave a `.ironbird/` it created (Task 4, "never touches ..." and the fixture test).
4. **Something on the daemon port that accepts connections but never answers HTTP** (a stuck process, a non-HTTP server). The check must fail within about a second, never hang (Task 1, "times out on a server that accepts but never answers"; Task 2, the timeout case).
5. **One probe throwing something unexpected** (malformed `simctl` JSON, an unreadable `node_modules`). The rest of the report must still print, with that check failed and its message, and no stack trace (Task 3, "fails on output it cannot read"; Task 5, "reports a check that throws ...").

```ts
/** A TCP server on an ephemeral loopback port that accepts connections and never writes a byte. */
async function silentServer(): Promise<number> {
  const sockets = new Set<net.Socket>();
  const server = net.createServer((socket) => sockets.add(socket));
  await new Promise<void>((resolve) => server.listen(0, '127.0.0.1', resolve));
  cleanups.push(

        server.close(resolve);
```

```ts
import { messageOf } from '@ironbird/core';
import { access, readFile, readdir } from 'node:fs/promises';
import net from 'node:net';
import path from 'node:path';
import { systemExec, type Exec } from '../devices';

/** What answered a `status` request on a port, if anything did. */
export type HttpProbe = { kind: 'response'; status: number; body: string } | { kind: 'timeout' } | { kind: 'unreachable'; code: string };

export type BindProbe = { ok: true } | { ok: false; code: string; message: string };

export interface InstalledPackage {
  name: string;
  /** Undefined when the package's `package.json` is missing, unreadable, or has no string `version`. */
  version: string | undefined;
  dir: string;
}

/**
 * Everything `ironbird doctor` learns from the machine, injected so each check is unit tested with
 * fakes (M5 design §11). The config and headless checks read the project's own files instead.
 */
export interface DoctorEnvironment {
  nodeVersion: string;
  platform: NodeJS.Platform;
  /** Runs `git`, `xcrun`, and `adb`. */
  exec: Exec;
  probeHttp(url: string, timeoutMs: number): Promise<HttpProbe>;
  tryBind(host: string, port: number): Promise<BindProbe>;
  listInstalledPackages(fromDir: string): Promise<InstalledPackage[]>;
}

/**
 * Sends the protocol's `status` operation (`POST /v1/rpc`, docs/protocol.md §3) with no token and
 * reports whatever answered. The timeout covers the body too, so a server that sends headers and
 * then stalls is a timeout rather than a hang. Never throws.
 */
export async function probeHttp(url: string, timeoutMs: number): Promise<HttpProbe> {
  try {
    const response = await fetch(url, {
      method: 'POST',
      headers: { 'content-type': 'application/json' },
      body: JSON.stringify({ op: 'status' }),
      redirect: 'manual',
      signal: AbortSignal.timeout(timeoutMs),
    });
    return { kind: 'response', status: response.status, body: await response.text() };
  } catch (error) {
    if ((error as { name?: unknown }).name === 'TimeoutError') return { kind: 'timeout' };
    const code = (error as { cause?: { code?: unknown } }).cause?.code;
    return { kind: 'unreachable', code: typeof code === 'string' ? code : messageOf(error) };
  }
}

/** Binds `host:port` the way `ironbird serve` does and releases it at once. Never throws. */
export function tryBind(host: string, port: number): Promise<BindProbe> {
  return new Promise((resolve) => {
    const server = net.createServer();
    server.once('error', (error: NodeJS.ErrnoException) => resolve({ ok: false, code: error.code ?? 'UNKNOWN', message: error.message }));
    server.listen(port, host, () => server.close(() => resolve({ ok: true })));
  });
}

const exists = (file: string): Promise<boolean> =>
  access(file).then(
    () => true,
    () => false,
  );

async function readVersion(dir: string): Promise<string | undefined> {
  try {
    const parsed: unknown = JSON.parse(await readFile(path.join(dir, 'package.json'), 'utf8'));
    const version = parsed !== null && typeof parsed === 'object' ? (parsed as { version?: unknown }).version : undefined;
    return typeof version === 'string' ? version : undefined;
  } catch {
    return undefined;
  }
}

/**
 * Every `@ironbird/*` package and the unscoped `ironbird` package visible from `fromDir`, found the
 * way Node resolves them: `node_modules` in `fromDir` and each directory above it, the nearest copy
 * of a name winning. pnpm's entries are symlinks, so nothing here filters on `isDirectory()`.
 */
export async function listInstalledPackages(fromDir: string): Promise<InstalledPackage[]> {
  const found = new Map<string, InstalledPackage>();
  let dir = path.resolve(fromDir);
  for (;;) {
    const modules = path.join(dir, 'node_modules');
    const scoped = await readdir(path.join(modules, '@ironbird')).catch(() => [] as string[]);
    const names = [...scoped.filter((name) => !name.startsWith('.')).map((name) => `@ironbird/${name}`), 'ironbird'];
    for (const name of names) {
      const packageDir = path.join(modules, ...name.split('/'));
      if (found.has(name) || !(await exists(packageDir))) continue;
      found.set(name, { name, version: await readVersion(packageDir), dir: packageDir });
    }
    const parent = path.dirname(dir);
    if (parent === dir) break;
    dir = parent;
  }
  return [...found.values()].sort((a, b) => (a.name < b.name ? -1 : a.name > b.name ? 1 : 0));
}

export function systemEnvironment(): DoctorEnvironment {
  return { nodeVersion: process.versions.node, platform: process.platform, exec: systemExec, probeHttp, tryBind, listInstalledPackages };
}
```

```ts
import type { DoctorEnvironment, HttpProbe } from './environment';

export type DoctorCheckId = 'node' | 'config' | 'headless' | 'port' | 'gitignore' | 'versions' | 'simctl' | 'adb';

/** One entry of `ironbird doctor`'s output (M5 design D6), with its keys in this order. */
export interface DoctorCheck {
  id: DoctorCheckId;
  ok: boolean;
  required: boolean;
  /** One line saying what was found. */
  detail: string;
  /** What to do about a failure; absent when there is nothing specific to do. */
  fix?: string;
}

export const MIN_NODE_MAJOR = 22;
/** How long the port check waits for whatever holds the daemon port to answer `status` (M5 design §6). */
export const PORT_PROBE_TIMEOUT_MS = 1_000;
export const SKIPPED_DETAIL = 'skipped: the config could not be loaded';
export const SKIPPED_FIX = 'Fix the config check first';

export function passCheck(id: DoctorCheckId, required: boolean, detail: string): DoctorCheck {
  return { id, ok: true, required, detail };
}

export function failCheck(id: DoctorCheckId, required: boolean, detail: string, fix?: string): DoctorCheck {
  return fix === undefined ? { id, ok: false, required, detail } : { id, ok: false, required, detail, fix };
}

export function checkNode(version: string): DoctorCheck {
  const major = Number.parseInt(version.replace(/^v/, '').split('.')[0] ?? '', 10);
  if (Number.isInteger(major) && major >= MIN_NODE_MAJOR) return passCheck('node', true, `Node ${version}`);
  return failCheck('node', true, `Node ${version}; ironbird needs Node ${MIN_NODE_MAJOR} or newer`, `Install Node ${MIN_NODE_MAJOR} or newer, for example the current LTS from nodejs.org`);
}

export interface PortConfig {
  host: string;
  port: number;
  bridgePort: number;
}

const LOOPBACK_FOR_WILDCARD: Record<string, string> = { '0.0.0.0': '127.0.0.1', '::': '::1' };

/** Where `doctor` sends `status`: a wildcard bind is reached over loopback, and IPv6 hosts are bracketed. */
export function statusUrl(host: string, port: number): string {
  const target = LOOPBACK_FOR_WILDCARD[host] ?? host;
  return `http://${target.includes(':') ? `[${target}]` : target}:${port}/v1/rpc`;
}

const isObject = (value: unknown): value is Record<string, unknown> => value !== null && typeof value === 'object' && !Array.isArray(value);

/**
 * Names an ironbird daemon from its answer to `status`, or returns undefined for anything else. A
 * daemon answers 200 `{ ok: true, result: { version, protocol, ... } }`, or 401 with an
 * `UNAUTHORIZED` envelope when it requires a token, which `doctor` never sends (M5 design §6).
 */
export function identifyDaemon(probe: HttpProbe): string | undefined {
  if (probe.kind !== 'response') return undefined;
  let body: unknown;
  try {
    body = JSON.parse(probe.body);
  } catch {
    return undefined;
  }
  if (!isObject(body)) return undefined;
  const { result, error } = body;
  if (probe.status === 200 && body['ok'] === true && isObject(result)) {
    const version = result['version'];
    const protocol = result['protocol'];
    if (typeof version === 'string' && typeof protocol === 'number') return `an ironbird daemon (version ${version}, protocol ${protocol})`;
  }
  if (probe.status === 401 && body['ok'] === false && isObject(error) && error['code'] === 'UNAUTHORIZED') return 'an ironbird daemon that requires a token';
  return undefined;
}

type PortFinding = { ok: true; ironbird: boolean; detail: string } | { ok: false; detail: string; fix: string };

/**
 * HTTP first, then a bind: on macOS a bind of 127.0.0.1 succeeds while a daemon holds 0.0.0.0 on
 * the same port, so only asking the port tells whether a daemon is there.
 */
async function inspectDaemonPort(host: string, port: number, env: Pick<DoctorEnvironment, 'probeHttp' | 'tryBind'>): Promise<PortFinding> {
  if (port === 0) return { ok: true, ironbird: false, detail: 'daemon port 0: the OS picks a free port at start' };
  const fix = `Change daemon.port in ironbird.config.ts, or stop the process using port ${port}`;
  const probe = await env.probeHttp(statusUrl(host, port), PORT_PROBE_TIMEOUT_MS);
  const daemon = identifyDaemon(probe);
  if (daemon !== undefined) return { ok: true, ironbird: true, detail: `daemon port ${port} is held by ${daemon}` };
  if (probe.kind === 'response') return { ok: false, detail: `daemon port ${port} on ${host} is in use by something that is not an ironbird daemon (HTTP ${probe.status})`, fix };
  if (probe.kind === 'timeout') return { ok: false, detail: `daemon port ${port} on ${host} is in use by something that did not answer within ${PORT_PROBE_TIMEOUT_MS / 1_000} s`, fix };
  const bind = await env.tryBind(host, port);
  if (bind.ok) return { ok: true, ironbird: false, detail: `daemon port ${port} on ${host} is free` };
  if (bind.code === 'EADDRINUSE') return { ok: false, detail: `daemon port ${port} on ${host} is in use by something that is not an ironbird daemon`, fix };
  return { ok: false, detail: `cannot bind ${host}:${port} (${bind.code}): ${bind.message}`, fix: 'Change daemon.host or daemon.port in ironbird.config.ts' };
}

async function inspectBridgePort(host: string, bridgePort: number, env: Pick<DoctorEnvironment, 'tryBind'>): Promise<PortFinding> {
  if (bridgePort === 0) return { ok: true, ironbird: false, detail: 'bridge port 0: the OS picks a free port at start' };
  const bind = await env.tryBind(host, bridgePort);
  if (bind.ok) return { ok: true, ironbird: false, detail: `bridge port ${bridgePort} is free` };
  const fix = `Change bridge.port in ironbird.config.ts, or stop the process using port ${bridgePort}`;
  if (bind.code === 'EADDRINUSE') return { ok: false, detail: `bridge port ${bridgePort} on ${host} is in use`, fix };
  return { ok: false, detail: `cannot bind ${host}:${bridgePort} (${bind.code}): ${bind.message}`, fix };
}

/**
 * The daemon port must be free or held by an ironbird daemon (M5 design §6). The bridge port must
 * be free too, since `ironbird serve` binds both, unless a daemon already holds the daemon port, in
 * which case it holds its bridge port as well. Equal fixed ports fail as `serve` itself would.
 */
export async function checkPort(ports: PortConfig | undefined, env: Pick<DoctorEnvironment, 'probeHttp' | 'tryBind'>): Promise<DoctorCheck> {
  if (ports === undefined) return failCheck('port', true, SKIPPED_DETAIL, SKIPPED_FIX);
  const { host, port, bridgePort } = ports;
  if (port !== 0 && port === bridgePort) return failCheck('port', true, `daemon.port and bridge.port are both ${port}`, 'Give daemon.port and bridge.port different values in ironbird.config.ts');
  const daemon = await inspectDaemonPort(host, port, env);
  if (!daemon.ok) return failCheck('port', true, daemon.detail, daemon.fix);
  if (daemon.ironbird) return passCheck('port', true, `${daemon.detail}; the bridge port is not checked while it runs`);
  const bridge = await inspectBridgePort(host, bridgePort, env);
  if (!bridge.ok) return failCheck('port', true, `${daemon.detail}, but ${bridge.detail}`, bridge.fix);
  return passCheck('port', true, `${daemon.detail}; ${bridge.detail}`);
}
```

```ts
const codeOf = (error: unknown): unknown => (error as { code?: unknown }).code;

/** The first line of a host tool's stderr, else the error's message. */
export function failureText(error: unknown): string {
  const stderr = (error as { stderr?: unknown }).stderr;
  const first = typeof stderr === 'string' ? stderr.trim().split('\n')[0] : undefined;
  return first ? first : messageOf(error);
}

/**
 * The artifacts directory (`.ironbird/` by default) must be ignored by git (M5 design §6), because it
 * holds state, events, and screenshots (architecture.md §9). Asked with a trailing slash: without
 * it, git reports a `.ironbird/` pattern as not matching while the directory doesn't exist yet, as
 * in a fresh clone.
 */
export async function checkGitignore(paths: { rootDir: string; artifactsPath: string }, env: Pick<DoctorEnvironment, 'exec'>): Promise<DoctorCheck> {
  const { rootDir, artifactsPath } = paths;
  const gitFix = `Run git status in ${rootDir} and fix what it reports`;
  try {
    await env.exec('git', ['-C', rootDir, 'rev-parse', '--show-toplevel']);
  } catch (error) {
    if (codeOf(error) === 'ENOENT') return passCheck('gitignore', true, 'git is not installed, so there is nothing to check');
    if (failureText(error).includes('not a git repository')) return passCheck('gitignore', true, 'not in a git repository');
    return failCheck('gitignore', true, `git rev-parse failed: ${failureText(error)}`, gitFix);
  }
  const shown = `${path.relative(rootDir, artifactsPath).split(path.sep).join('/') || '.'}/`;
  try {
    await env.exec('git', ['-C', rootDir, 'check-ignore', '-q', '--', shown]);
    return passCheck('gitignore', true, `${shown} is ignored by git`);
  } catch (error) {
    if (codeOf(error) === 1) return failCheck('gitignore', true, `${shown} is not ignored by git, so state, events, and screenshots could be committed`, `Add ${shown} to ${path.join(rootDir, '.gitignore')}`);
    if (failureText(error).includes('outside repository')) return passCheck('gitignore', true, `${shown} is outside the git repository`);
    return failCheck('gitignore', true, `git check-ignore failed: ${failureText(error)}`, gitFix);
  }
}

const VERSION_PATTERN = /^(\d+)\.(\d+)\.(\d+)(?:-.+)?$/;

function compareKeys(a: number[], b: number[]): number {
  for (let index = 0; index < a.length; index += 1) {
    const difference = (a[index] ?? 0) - (b[index] ?? 0);
    if (difference !== 0) return difference;
  }
  return 0;
}

/** The highest of `versions` by major, minor, and patch, a prerelease ranking below its release; strings that aren't `x.y.z[-pre]` are ignored. */
export function newestVersion(versions: string[]): string | undefined {
  let best: { version: string; key: number[] } | undefined;
  for (const version of versions) {
    const match = VERSION_PATTERN.exec(version);
    if (!match) continue;
    const key = [Number(match[1]), Number(match[2]), Number(match[3]), version.includes('-') ? 0 : 1];
    if (best === undefined || compareKeys(key, best.key) > 0) best = { version, key };
  }
  return best?.version;
}

/**
 * Every installed `@ironbird/*` package, the `ironbird` package, and the running CLI must have one
 * version (M5 design §6): a CLI from `npx` or a global install that differs from the app's packages
 * is the skew the M3 eval hit. Changesets releases them as one fixed group, so equal is the norm.
 */
export async function checkVersions(rootDir: string, runningVersion: string, env: Pick<DoctorEnvironment, 'listInstalledPackages'>): Promise<DoctorCheck> {
  const installed = await env.listInstalledPackages(rootDir);
  if (installed.length === 0) {
    return failCheck('versions', true, `No ironbird packages are installed in ${rootDir} or above it`, `Install @ironbird/core and @ironbird/react-native, and @ironbird/cli as a dev dependency, all at ${runningVersion}`);
  }
  const entries: Array<{ name: string; version: string | undefined }> = [...installed.map(({ name, version }) => ({ name, version })), { name: 'this CLI', version: runningVersion }];
  const detail = entries.map(({ name, version }) => `${name} ${version ?? '(no readable version)'}`).join(', ');
  const versions = new Set(entries.map(({ version }) => version));
  if (versions.size === 1 && !versions.has(undefined)) return passCheck('versions', true, detail);
  const target = newestVersion(entries.flatMap(({ version }) => (version === undefined ? [] : [version]))) ?? runningVersion;
  return failCheck(
    'versions',
    true,
    detail,
    `Install one version of every ironbird package, for example ${installed.map(({ name }) => `${name}@${target}`).join(' ')}, and run the CLI installed in the project (npx ironbird) so it matches`,
  );
}

/** Informational (M5 design §6): iOS work needs macOS and `xcrun simctl`; the detail lists booted simulators. */
export async function checkSimctl(env: Pick<DoctorEnvironment, 'platform' | 'exec'>): Promise<DoctorCheck> {
  if (env.platform !== 'darwin') return failCheck('simctl', false, `iOS simulators need macOS; this machine runs ${env.platform}`);
  try {
    const booted = await listBootedSimulators(env.exec);
    if (booted.length === 0) return passCheck('simctl', false, 'xcrun simctl is available; no simulator is booted');
    return passCheck('simctl', false, `xcrun simctl is available; booted: ${booted.map((device) => `${device.name ?? 'unnamed'} (${device.id})`).join(', ')}`);
  } catch (error) {
    return failCheck('simctl', false, `xcrun simctl is unavailable: ${failureText(error)}`, 'Install Xcode, open it once to finish installing its components, and select it with sudo xcode-select -s /Applications/Xcode.app');
  }
}

/** Informational (M5 design §6): Android work needs `adb`; the detail lists connected devices. */
export async function checkAdb(env: Pick<DoctorEnvironment, 'exec'>): Promise<DoctorCheck> {
  try {
    const devices = await listAndroidDevices(env.exec);
    if (devices.length === 0) return passCheck('adb', false, 'adb is available; no device is connected');
    return passCheck('adb', false, `adb is available; devices: ${devices.map((device) => (device.name ? `${device.name} (${device.id})` : device.id)).join(', ')}`);
  } catch (error) {
    if (codeOf(error) === 'ENOENT') return failCheck('adb', false, 'adb is not on the PATH', 'Install the Android SDK Platform-Tools and add them to your PATH');
    return failCheck('adb', false, `adb failed: ${failureText(error)}`, 'Run adb devices and fix what it reports');
  }
}
```

```ts
import { isHeadlessDefinition, isIronbirdError, messageOf } from '@ironbird/core';
import { access, mkdir, mkdtemp, rm, rmdir } from 'node:fs/promises';
import path from 'node:path';
import { loadTypeScriptModule } from '../bundle';
import { defaultConfig, findConfigFile, loadConfig, type ResolvedConfig } from '../config';
import { SKIPPED_DETAIL, SKIPPED_FIX, failCheck, passCheck, type DoctorCheck } from './checks';

export const CONFIG_DOCS_URL = 'https://github.com/ironbird-dev/ironbird/blob/main/docs/api.md#defineconfig-p0';

const HEADLESS_CHAIN_FIX = 'Headless code runs in Node, so nothing it imports may import react-native: move that import out of this chain, for example behind a port with a fake';

/** What the later checks may use: the loaded config, the defaults when there is no config file, or only the project root when the config couldn't be loaded. */
export type ConfigOutcome = { status: 'loaded'; rootDir: string; config: ResolvedConfig } | { status: 'missing'; rootDir: string; config: ResolvedConfig } | { status: 'invalid'; rootDir: string };

export interface ProjectChecks {
  config: DoctorCheck;
  headless: DoctorCheck;
  outcome: ConfigOutcome;
}

const exists = (file: string): Promise<boolean> =>
  access(file).then(
    () => true,
    () => false,
  );

interface Scratch {
  dir: string;
  remove(): Promise<void>;
}

/**
 * A fresh directory under `<rootDir>/.ironbird/` for this run's bundles. It sits beside the daemon's
 * `.ironbird/cache`, so bare imports in the emitted bundles resolve from the same `node_modules`
 * (esbuild leaves packages external), but it is never `.ironbird/cache` itself, which a running
 * daemon owns (M5 design §6). `remove` deletes it, and `.ironbird/` as well when this run created
 * it, using `rmdir` so a directory something else has written into since is left alone.
 */
async function createScratch(rootDir: string): Promise<Scratch> {
  const parent = path.join(rootDir, '.ironbird');
  const created = await mkdir(parent, { recursive: true });
  const removeParent = async (): Promise<void> => {
    if (created !== undefined) await rmdir(parent).catch(() => undefined);
  };
  let dir: string;
  try {
    dir = await mkdtemp(path.join(parent, 'doctor-'));
  } catch (error) {
    await removeParent();
    throw error;
  }
  return {
    dir,
    async remove() {
      await rm(dir, { recursive: true, force: true }).catch(() => undefined);
      await removeParent();
    },
  };
}

function missingConfig(cwd: string, file: string | undefined): DoctorCheck {
  const target = file ?? path.join(cwd, 'ironbird.config.ts');
  const detail = file === undefined ? `No ironbird.config.ts in ${cwd} or any directory above it` : `${path.relative(cwd, file)} does not exist`;
  return failCheck('config', true, detail, `Create ${target} that default-exports defineConfig({ appId: '<your app id>' }) from @ironbird/cli/config; see ${CONFIG_DOCS_URL}`);
}

/** The `INVALID_CONFIG` issues as `path: message`, joined with `; `, else the error's message. */
function issuesOf(error: unknown): string {
  if (isIronbirdError(error) && error.code === 'INVALID_CONFIG') {
    const issues = (error.details as { issues?: unknown } | undefined)?.issues;
    if (Array.isArray(issues) && issues.length > 0) {
      return issues
        .map((issue: { path?: unknown; message?: unknown }) => {
          const at = Array.isArray(issue.path) ? issue.path.map(String).join('.') : '';
          const message = String(issue.message);
          return at === '' ? message : `${at}: ${message}`;
        })
        .join('; ');
    }
  }
  return messageOf(error);
}

/**
 * Loads the headless entry the way `ironbird serve` does, with `react-native` forbidden, and checks
 * its default export. Loading runs the module's top-level code; `create` is never called.
 */
async function checkHeadless(config: ResolvedConfig, cwd: string, scratchDir: string): Promise<DoctorCheck> {
  if (config.headlessPath === undefined) return passCheck('headless', true, 'not configured');
  const shown = path.relative(cwd, config.headlessPath);
  try {
    const loaded = await loadTypeScriptModule(config.headlessPath, { outDir: scratchDir, label: 'headless', forbidden: ['react-native'] });
    if (!isHeadlessDefinition(loaded.exports['default'])) return failCheck('headless', true, `${shown} must default-export defineHeadless(...)`, `Default-export defineHeadless(...) from @ironbird/core in ${shown}`);
    return passCheck('headless', true, `${shown} loads`);
  } catch (error) {
    const chain = isIronbirdError(error) ? (error.details as { importChain?: unknown } | undefined)?.importChain : undefined;
    if (Array.isArray(chain) && chain.length > 0) {
      return failCheck('headless', true, `${String(chain[chain.length - 1])} is imported in the headless graph: ${chain.map(String).join(' > ')}`, HEADLESS_CHAIN_FIX);
    }
    return failCheck('headless', true, messageOf(error));
  }
}

/**
 * The `config` and `headless` checks (M5 design §6). The config is found as every command finds it:
 * `configPath` (`--config`), else the nearest config file walking up from `cwd`. Unlike `loadConfig`,
 * a missing file fails here; the later checks then use the defaults, rooted at `cwd`.
 */
export async function checkProject(options: { cwd: string; configPath?: string | undefined }): Promise<ProjectChecks> {
  const cwd = path.resolve(options.cwd);
  const file = options.configPath === undefined ? await findConfigFile(cwd) : path.resolve(cwd, options.configPath);
  if (file === undefined || !(await exists(file))) {
    return { config: missingConfig(cwd, file), headless: passCheck('headless', true, 'not configured'), outcome: { status: 'missing', rootDir: cwd, config: defaultConfig(cwd) } };
  }
  const rootDir = path.dirname(file);
  const shown = path.relative(cwd, file);
  const skippedHeadless = failCheck('headless', true, SKIPPED_DETAIL, SKIPPED_FIX);
  let scratch: Scratch;
  try {
    scratch = await createScratch(rootDir);
  } catch (error) {
    const parent = path.join(rootDir, '.ironbird');
    return {
      config: failCheck('config', true, `Cannot create a temporary directory under ${parent}: ${messageOf(error)}`, `Make ${rootDir} writable, and remove anything at ${parent} that isn't a directory`),
      headless: skippedHeadless,
      outcome: { status: 'invalid', rootDir },
    };
  }
  try {
    let config: ResolvedConfig;
    try {
      config = await loadConfig({ cwd, configPath: file, cacheDir: scratch.dir });
    } catch (error) {
      return { config: failCheck('config', true, `${shown} is invalid: ${issuesOf(error)}`, `Fix ${shown}; see ${CONFIG_DOCS_URL}`), headless: skippedHeadless, outcome: { status: 'invalid', rootDir } };
    }
    return { config: passCheck('config', true, `${shown} is valid`), headless: await checkHeadless(config, cwd, scratch.dir), outcome: { status: 'loaded', rootDir, config } };
  } finally {
    await scratch.remove();
  }
}
```

```ts
import { messageOf } from '@ironbird/core';
import path from 'node:path';
import { checkAdb, checkGitignore, checkNode, checkPort, checkSimctl, checkVersions, failCheck, type DoctorCheck, type DoctorCheckId } from './checks';
import { systemEnvironment, type DoctorEnvironment } from './environment';
import { checkProject, type ProjectChecks } from './project';

/** What `ironbird doctor` prints (M5 design D6). */
export interface DoctorReport {
  checks: DoctorCheck[];
}

export interface DoctorOptions {
  cwd: string;
  /** `--config`; default is the nearest config file walking up from `cwd`. */
  configPath?: string | undefined;
  /** The running CLI's version, compared with the installed packages. */
  version: string;
  /** Test hook: replaces parts of the probed environment. */
  environment?: Partial<DoctorEnvironment> | undefined;
}

const unexpected = (error: unknown): string => `check failed unexpectedly: ${messageOf(error)}`;

/** One check's fault becomes that check's failure, so the rest of the report still prints. */
async function guard(id: DoctorCheckId, required: boolean, run: () => DoctorCheck | Promise<DoctorCheck>): Promise<DoctorCheck> {
  try {
    return await run();
  } catch (error) {
    return failCheck(id, required, unexpected(error));
  }
}

/** Runs the checks of M5 design §6, one at a time and in its order, without a daemon. */
export async function runDoctor(options: DoctorOptions): Promise<DoctorReport> {
  const env: DoctorEnvironment = { ...systemEnvironment(), ...options.environment };
  const cwd = path.resolve(options.cwd);
  const node = await guard('node', true, () => checkNode(env.nodeVersion));
  let project: ProjectChecks;
  try {
    project = await checkProject({ cwd, configPath: options.configPath });
  } catch (error) {
    project = { config: failCheck('config', true, unexpected(error)), headless: failCheck('headless', true, unexpected(error)), outcome: { status: 'invalid', rootDir: cwd } };
  }
  const { outcome } = project;
  const config = outcome.status === 'invalid' ? undefined : outcome.config;
  const { rootDir } = outcome;
  const ports = config === undefined ? undefined : { host: config.daemon.host, port: config.daemon.port, bridgePort: config.bridge.port };
  const artifactsPath = config?.artifactsPath ?? path.join(rootDir, '.ironbird');
  return {
    checks: [
      node,
      project.config,
      project.headless,
      await guard('port', true, () => checkPort(ports, env)),
      await guard('gitignore', true, () => checkGitignore({ rootDir, artifactsPath }, env)),
      await guard('versions', true, () => checkVersions(rootDir, options.version, env)),
      await guard('simctl', false, () => checkSimctl(env)),
      await guard('adb', false, () => checkAdb(env)),
    ],
  };
}

/** 0 when every required check passes, 1 otherwise; optional checks never change it (M5 design D6). */
export function doctorExitCode(report: DoctorReport): 0 | 1 {
  return report.checks.every((check) => check.ok || !check.required) ? 0 : 1;
}
```

~~~markdown
### doctor

Checks that the project and this machine are ready for ironbird, without a daemon. Prints `{ checks: [{ id, ok, required, detail, fix? }] }`, one entry per check in the order below, and exits 0 when every required check passes and 1 otherwise; optional checks never change the exit code. `detail` is one line saying what was found, and `fix`, present on most failures, says what to do.

| id | Required | Passes when |
|---|---|---|
| `node` | yes | Node is 22 or newer |
| `config` | yes | The config file exists and validates. A missing file fails with a fix naming the file to create; an invalid one lists its `INVALID_CONFIG` issues |

| `gitignore` | yes | The artifacts directory, `.ironbird/` by default, is ignored by git, or the project isn't in a git repository |

| `adb` | no | `adb` is on the path; `detail` lists connected devices |
~~~

|---|---|---|---|
| 1 | §6 `port`: "identified by `GET /v1/status`" | No such route exists. `status` is `POST /v1/rpc` `{ op: 'status' }`; a `GET /v1/status` gets 404 `UNSUPPORTED` (or 401 when the daemon has a token) | Probe `POST /v1/rpc` with `{ op: 'status' }`, no token, 1 s timeout.
