## Global Constraints

Copied from [AGENTS.md](../../../AGENTS.md) hard rules:

1. `@ironbird/core` imports only `zod`. No `react-native`, no `node:*` modules, no DOM or browser globals. It must run unmodified in Node and Hermes. Lint enforces this.
2. No arbitrary code execution anywhere. No `eval`, no `new Function`, and no protocol operation that runs caller-supplied code. Agents act only through declared commands and fake controls ([ADR-0001](../../adr/0001-commands-only-agent-surface.md)).
3. The bridge stays dev-only. `startBridge` must no-op when `__DEV__` is false unless `allowInNonDevBuilds` is set, and the bridge marker must stay referenced in the `hello` message so `ironbird verify-bundle` can detect it after minification. The marker constant is defined in `@ironbird/react-native` and nowhere else: `@ironbird/core` ships in release bundles, so the string must not appear in it or in any other package.
4. Validate every payload where it is applied, including inside the app. Never trust the daemon.
5. Protocol changes update [docs/protocol.md](../../protocol.md) in the same PR. Breaking changes bump `PROTOCOL_VERSION` and need an ADR.
6. Public API or CLI changes update [docs/api.md](../../api.md) or [docs/cli.md](../../cli.md) in the same PR and include a changeset.
7. New runtime dependencies in `core` or `react-native` need an ADR. New dependencies in `cli` need a one-line justification in the PR.
8. Errors that cross a package boundary are `IronbirdError` with a code from the protocol error table. No bare string throws.
9. Headless determinism is a feature. Library code and example app logic take time from the injected `Clock`, never from global `setTimeout`, `setInterval`, or `Date.now`. The bridge is library code too: it uses the `Clock` passed to `startBridge`, which defaults to the real clock. `requestAnimationFrame` is a rendering signal rather than a clock and may be used directly. Inside `@ironbird/core`, `clock.ts` and `scheduler.ts` are the only files that may use global timers or `Date.now`, and lint enforces that.

### Task 1: `defineCommands` rejects schemas that aren't Zod 4.2+

Dropping Zod 3 (D9) makes `zod/v3` the place where an app's legacy schemas live, so the likeliest mistake is passing one of them to ironbird. Today that passes `defineCommands` and fails later with a bare `TypeError` in `describe()`, which breaks hard rule 8. This task makes it fail at definition time with `INVALID_CONFIG`.

**Files:**
- Modify: `packages/core/src/registry.ts` (add `schemaProblem` above `defineCommands`; check every schema at the top of `defineCommands`)
- Test: `packages/core/src/registry.test.ts`, `packages/core/src/fake.test.ts`
- Modify: `docs/protocol.md` (§6, the `INVALID_CONFIG` row), `docs/api.md` (`defineCommands`)
- Create: `.changeset/m5-zod-schema-check.md`

**Interfaces:**
- Consumes: nothing new.
- Produces: `defineCommands(schemas)` throws `IronbirdError('INVALID_CONFIG', message, { name, reason })` for the first schema that is not a Zod 4.2+ classic schema. `reason` is exactly one of `"it is a Zod 3 schema (from zod 3, or from 'zod/v3')"`, `"it is a Zod 4 schema without a toJSONSchema method (from 'zod/mini', or from zod before 4.2)"`, `'it is not a Zod schema'`. The message is exactly `` `The schema for ${name} can't be used: ${reason}. ironbird needs zod 4.2 or later, with schemas from 'zod' or 'zod/v4'; see docs/migrating-from-zod-3.md` ``. A fake's `create` inherits it (it calls `defineCommands(definition.controls)`), with `name` the control name. Task 2's migration note quotes this behavior.

- [ ] **Step 3: Implement the check**

In `packages/core/src/registry.ts`, add this function directly above `export function defineCommands`:

```ts
/**
 * Why `schema` can't serve as a command or control schema, or undefined when it can (M5 design D9,
 * spec Q8). The registry validates through the schema's own `safeParse` and describes it through its
 * own `toJSONSchema`, which only Zod 4.2+ classic schemas (`zod`, `zod/v4`) have. The check is
 * structural, because core never loads zod: Zod 3 schemas (`zod` 3, `zod/v3`) carry `_def` and no
 * `_zod`; `zod/mini` schemas, and classic schemas before 4.2, carry `_zod` but no `toJSONSchema`.
 */
function schemaProblem(schema: unknown): string | undefined {
  if (typeof schema !== 'object' || schema === null) return 'it is not a Zod schema';
  const candidate = schema as { safeParse?: unknown; toJSONSchema?: unknown };
  const zod4 = '_zod' in schema;

- [ ] **Step 2: Write `docs/migrating-from-zod-3.md`**

````markdown
# Migrating from Zod 3

| | |
|---|---|
| Applies to | ironbird 0.1 and later |
| Last updated | 2026-10-04 |
| Related | [api.md](api.md) (`defineCommands`, `defineFake`) · [ADR-0004](adr/0004-zod-4-schemas.md) · [spec.md](spec.md) Q8 |

ironbird describes every command and fake control to agents as JSON Schema, and it gets that JSON Schema from each schema's own `toJSONSchema` method, which Zod added in 4.2. So ironbird needs the `zod` package at 4.2 or later: `zod` is a peer dependency of `@ironbird/core`, `@ironbird/redux`, `@ironbird/xstate`, and `@ironbird/testing`, with the range `^4.2.0`. Zod 3 is not supported (spec Q8, closed in M5).

An app still on Zod 3 doesn't have to migrate all its schemas first. Zod 4 ships the Zod 3 API at the subpath `zod/v3`, so the old schemas keep working while the schemas you give ironbird use Zod 4.

## Steps

1. Install Zod 4:

   ```sh
   npm install zod@^4.2
   ```

2. Point the schemas you haven't migrated at the Zod 3 API that Zod 4 carries. Only the import changes:

   ```ts
   // before
   import { z } from 'zod';
   // after, for a schema still written against Zod 3
   import { z } from 'zod/v3';
   ```

   Zod's own guide covers moving each schema to Zod 4 later: <https://zod.dev/v4/changelog>.

3. Write the schemas you give ironbird, in `defineCommands` and in `defineFake`'s `controls`, against Zod 4, imported from `zod` or `zod/v4`:

   ```ts
   import { z } from 'zod';
   import { defineCommands } from '@ironbird/core';

   export const commands = defineCommands({
     'cart.addItem': z.object({ sku: z.string(), qty: z.number().int().positive() }).describe('Add an item to the cart'),
   });
   ```

## What doesn't work

- **A Zod 3 schema in `defineCommands` or in a fake's `controls`.** TypeScript rejects it with `TS2740`: the Zod 3 object lacks `toJSONSchema` and the other Zod 4 members. Without type checking, `defineCommands`, or the fake's `create`, throws `IronbirdError` with code `INVALID_CONFIG`, details `{ name, reason }`, and a message that names the schema and this page; a headless entry that throws it fails to load with `HEADLESS_LOAD_FAILED` carrying that message.
- **`zod/mini` schemas.** They have no `toJSONSchema` method, so they fail the same way.
- **`zod` 3.25.x.** It offers a `zod/v4` subpath, but the package's own version, 3.25, doesn't satisfy ironbird's `^4.2.0` peer range, so package managers report the peer dependency as unmet (npm stops with `ERESOLVE`). Install `zod@^4.2` instead.
- **Nesting across versions.** A `zod/v3` schema can't be used inside a Zod 4 schema, or the other way round.

## Sharing a shape between old and new schemas

When a command's payload has the same shape as a schema that is still on Zod 3, write the Zod 4 schema next to it and let TypeScript check that the two infer the same type:

```ts
import { z as z3 } from 'zod/v3';
import { z } from 'zod';

export const legacyItem = z3.object({ sku: z3.string(), qty: z3.number().int() });
export const addItem = z.object({ sku: z.string(), qty: z.number().int() });

type Same<A, B> = [A] extends [B] ? ([B] extends [A] ? true : false) : false;
// Fails to compile when the two shapes drift apart.
export const sameShape: Same<z3.infer<typeof legacyItem>, z.infer<typeof addItem>> = true;
```
````

  '@ironbird/core': ['.'],
  '@ironbird/react-native': ['.'],
  '@ironbird/redux': ['.'],
  '@ironbird/xstate': ['.'],
  '@ironbird/testing': ['.'],
  '@ironbird/cli': ['./config', './runner'],
  ironbird: [],
};

/** The zod peer range the M5 design fixes (D9), and the packages that must declare it. */
export const ZOD_PEER = '^4.2.0';
export const ZOD_PEER_PACKAGES = ['@ironbird/core', '@ironbird/redux', '@ironbird/testing', '@ironbird/xstate'];

const FORBIDDEN = [
  [/(^|\/)(src|test|tests|__tests__|scripts|jest)\//, 'a source, test, or script folder'],
  [/\.test\.[cm]?[jt]sx?$/, 'a test file'],
  [/\.tsbuildinfo$/, 'a TypeScript build cache'],
  [/(^|\/)tsconfig[^/]*\.json$/, 'a tsconfig'],
  [/(^|\/)(tsup|vitest|jest|stryker)[^/]*\.config\.[cm]?[jt]s$/, 'a tool config'],
];

const strip = (file) => file.replace(/^\.\//, '');

/** Every file package.json points at (`exports` leaves, `main`, `module`, `types`, `bin`), without `./`, sorted. */
export function exportTargets(manifest) {
  const targets = new Set();
  const add = (value) => {
    if (typeof value === 'string') targets.add(strip(value));
  };
  const walk = (node) => {
    if (typeof node === 'string') add(node);
    else if (node && typeof node === 'object') for (const [key, value] of Object.entries(node)) if (key !== './package.json') walk(value);
  };
  walk(manifest.exports);
  add(manifest.main);
  add(manifest.module);
  add(manifest.types);
  if (typeof manifest.bin === 'string') add(manifest.bin);
  else if (manifest.bin && typeof manifest.bin === 'object') for (const value of Object.values(manifest.bin)) add(value);
  return [...targets].sort();
}

/** Problems with the files one packed package ships, given its packed manifest. */
export function packProblems({ name, manifest, files }) {
  const problems = [];
  const have = new Set(files);
  for (const required of ['package.json', 'LICENSE', 'README.md']) if (!have.has(required)) problems.push(`${required} is missing`);
  for (const file of files) {
    const hit = FORBIDDEN.find(([pattern]) => pattern.test(file));
    if (hit) problems.push(`${file} should not ship (${hit[1]})`);
    else if (/\.(ts|tsx|mts|cts)$/.test(file) && !/\.d\.(ts|mts|cts)$/.test(file)) problems.push(`${file} should not ship (TypeScript source)`);
  }
  for (const target of exportTargets(manifest)) if (!have.has(target)) problems.push(`${target} is named in package.json but not packed`);
  for (const key of DUAL_ENTRIES[name] ?? []) {
    const entry = manifest.exports?.[key];
    for (const condition of ['import', 'require']) {
      for (const field of ['types', 'default']) if (typeof entry?.[condition]?.[field] !== 'string') problems.push(`exports["${key}"].${condition}.${field} is missing`);
    }
  }
  return problems;
}

/**
 * Problems with a packed manifest. `internal` lists the workspace's public package names;
 * `expectVersion`, when given, is the version every package and internal dependency must carry.
 */
export function manifestProblems({ manifest, internal, expectVersion }) {
  const problems = [];
  if (manifest.license !== 'MIT') problems.push(`license is ${manifest.license ?? 'missing'}, not MIT`);
  if (expectVersion !== undefined && manifest.version !== expectVersion) problems.push(`version is ${manifest.version}, not ${expectVersion}`);
  for (const field of ['dependencies', 'peerDependencies', 'optionalDependencies']) {
    for (const [dependency, range] of Object.entries(manifest[field] ?? {})) {
      const text = String(range);
      if (field === 'dependencies' && internal.includes(dependency) && expectVersion !== undefined && text !== expectVersion) problems.push(`dependencies.${dependency} is ${text}, not ${expectVersion}`);
      if (field === 'peerDependencies' && internal.includes(dependency) && /^\d+\.\d+\.\d+$/.test(text)) problems.push(`peerDependencies.${dependency} pins exactly ${text}; use a range`);
      if (text.startsWith('workspace:')) problems.push(`${field}.${dependency} is still ${text}`);
    }
  }
  if (ZOD_PEER_PACKAGES.includes(manifest.name) && manifest.peerDependencies?.zod !== ZOD_PEER) {
    problems.push(`peerDependencies.zod is ${manifest.peerDependencies?.zod ?? 'missing'}, not ${ZOD_PEER} (M5 design D9)`);
  }
  return problems;
}

/** Problems with the set of public package names: anything unexpected, anything missing. */
export function publishedProblems(names) {
  const problems = [];
  for (const name of names) if (!EXPECTED_PUBLISHED.includes(name)) problems.push(`${name} would be published but is not in EXPECTED_PUBLISHED`);
  for (const name of EXPECTED_PUBLISHED) if (!names.includes(name)) problems.push(`${name} is expected to publish but no public package has that name`);
  return problems;
}

```js
// Named imports of ironbird packages in the docs' code blocks must exist in the built packages, so
// the 0.1 README, the guides, and the package READMEs can't drift from the code. Pure helpers;
// doc-imports.test.mjs applies them to the real docs against dist/.

/** The names a declaration file exports: its `export { ... };` statements (tsup's form) and `export declare` lines. `type` prefixes are dropped; aliases count by their exported name. */
export function exportedNames(dts) {
  const names = new Set();
  for (const match of dts.matchAll(/export\s*\{([^}]*)\}\s*;/g)) {
    for (const part of match[1].split(',')) {
      const item = part.trim().replace(/^type\s+/, '');
      if (item) names.add(item.split(/\s+as\s+/).at(-1).trim());
    }
  }
  for (const match of dts.matchAll(/export\s+(?:declare\s+)?(?:function|const|let|class|interface|type|enum)\s+([A-Za-z_$][\w$]*)/g)) names.add(match[1]);
  return [...names].sort();
}

const OPEN = /^\s*```(ts|tsx|js|jsx|mjs|cjs)\s*$/;
const CLOSE = /^\s*```\s*$/;
const IMPORT = /import\s+(?:type\s+)?\{([^}]*)\}\s*from\s*['"](@ironbird\/[^'"]+|ironbird)['"]/g;

/** `import { ... } from '@ironbird/...'` statements inside TypeScript and JavaScript fences, as `{ specifier, names, line }` (1-based line of the `import`). */
export function importsInMarkdown(text) {
  const lines = text.split('\n');
  const found = [];
  for (let index = 0; index < lines.length; index += 1) {
    if (!OPEN.test(lines[index])) continue;
    const start = index + 1;
    let end = start;
    while (end < lines.length && !CLOSE.test(lines[end])) end += 1;
    const code = lines.slice(start, end).join('\n');
    for (const match of code.matchAll(IMPORT)) {
      const names = match[1]
        .split(',')
        .map((part) => part.trim().replace(/^type\s+/, '').split(/\s+as\s+/)[0].trim())
        .filter(Boolean);
      found.push({ specifier: match[2], names, line: start + 1 + (code.slice(0, match.index).split('\n').length - 1) });
    }
    index = end;
  }
  return found;
}

/** The declaration file a subpath (`.`, `./config`) of a manifest resolves to, or undefined. */
export function declarationFile(manifest, subpath) {
  const entry = manifest.exports?.[subpath];
  const types = entry && typeof entry === 'object' ? (entry.import?.types ?? entry.types ?? entry.require?.types) : undefined;
  return types ?? (subpath === '.' ? manifest.types : undefined);
}

/** `{ dir, types }` for a specifier such as `@ironbird/cli/config`, among `packages` (`{ dir, manifest }`), or undefined. */
export function resolveSpecifier(specifier, packages) {
  const parts = specifier.split('/');
  const name = specifier.startsWith('@') ? parts.slice(0, 2).join('/') : parts[0];
  const rest = specifier.slice(name.length);
  const found = packages.find((candidate) => candidate.manifest.name === name);
  if (!found) return undefined;
  const types = declarationFile(found.manifest, rest === '' ? '.' : `.${rest}`);
  return types ? { dir: found.dir, types } : undefined;
}

/** The docs whose imports are checked: the README, each package's README, and docs/ except design plans and eval records. */
export function isCheckedDoc(rel) {
  if (rel === 'README.md' || /^packages\/[^/]+\/README\.md$/.test(rel)) return true;
  return rel.startsWith('docs/') && rel.endsWith('.md') && !rel.startsWith('docs/superpowers/') && !rel.startsWith('docs/evals/');
}

## 2. Make the store buildable in Node

The daemon runs your logic in Node, so the store and everything it imports must not import `react-native`. Ports, the interfaces through which the logic reaches the outside world, are passed in, so headless mode can pass fakes. Effects that call a port, here a listener middleware, run as usual.

```ts
// src/ports.ts
export interface CartApi {
  submitOrder(items: Array<{ sku: string; qty: number }>): Promise<{ orderId: string }>;
}

export interface Ports {
  api: CartApi;
}
```

```ts
// src/cart.ts
import { createSlice, type PayloadAction } from '@reduxjs/toolkit';

export interface CartState {
  items: Array<{ sku: string; qty: number }>;
  status: 'open' | 'submitting' | 'confirmed';
  orderId?: string;
}

const initialState: CartState = { items: [], status: 'open' };

export const cartSlice = createSlice({
  name: 'cart',
  initialState,
  reducers: {
    addItem(state, action: PayloadAction<{ sku: string; qty: number }>) {
      state.items.push(action.payload);
    },
    checkoutRequested(state) {
      state.status = 'submitting';
    },
    orderConfirmed(state, action: PayloadAction<{ orderId: string }>) {
      state.status = 'confirmed';
      state.orderId = action.payload.orderId;
    },
  },
});
```

```ts
// src/store.ts
import { configureStore, createListenerMiddleware } from '@reduxjs/toolkit';
import { cartSlice, type CartState } from './cart';
import type { Ports } from './ports';

export function makeStore(ports: Ports) {
  const listener = createListenerMiddleware();
  listener.startListening({
    actionCreator: cartSlice.actions.checkoutRequested,
    effect: async (_action, api) => {
      const { cart } = api.getState() as { cart: CartState };
      const { orderId } = await ports.api.submitOrder(cart.items);
      api.dispatch(cartSlice.actions.orderConfirmed({ orderId }));
    },
  });
  return configureStore({
    reducer: { cart: cartSlice.reducer },
    middleware: (getDefault) => getDefault().prepend(listener.middleware),
  });
}

export type AppStore = ReturnType<typeof makeStore>;
```

If a `react-native` import sneaks into this graph, the daemon refuses to load it with `HEADLESS_LOAD_FAILED` and prints the chain of imports that led to it.

## 4. Fake the ports

A fake implements a port for headless runs and declares controls, so a scenario or an agent can script the outside world. It takes time from the `clock` it is given, never from global timers, so headless runs are deterministic.

```ts
// src/ironbird/fakes.ts
import { z } from 'zod';
import { defineFake } from '@ironbird/core';
import type { CartApi } from '../ports';

export const fakeApi = defineFake('api', {
  description: 'The order API',
  controls: {
    setLatency: z.object({ ms: z.number().int().min(0) }).describe('Delay every response by this many milliseconds'),
    failNext: z.object({}).describe('Make the next submitOrder call reject'),
  },
  create({ clock, record }) {
    let latencyMs = 200;
    let failNext = false;
    let next = 1;
    const port: CartApi = {
      submitOrder: (items) =>
        new Promise((resolve, reject) => {
          clock.setTimeout(
            () => {
              if (failNext) {
                failNext = false;
                reject(new Error('order rejected'));
                return;
              }
              const orderId = `order-${next++}`;
              record('order.submitted', { orderId, items: items.length });
              resolve({ orderId });
            },
            latencyMs,
            'api.submitOrder',
          );
        }),
    };
    return {
      port,
      controls: {
        setLatency: ({ ms }) => {
          latencyMs = ms;
        },
        failNext: () => {
          failNext = true;
        },
      },
    };
  },
});
```

## 5. Adapt the store

`fromStore` turns a store into a target, the thing the daemon drives. By default a command becomes the action `{ type: name, payload }`; when your actions are named differently, map them with `toAction`:

```ts
// src/ironbird/target.ts
import { fromStore } from '@ironbird/redux';
import { cartSlice } from '../cart';
import type { AppStore } from '../store';
import { commands } from './commands';

export const toTarget = (store: AppStore) =>
  fromStore(store, {
    commands,
    toAction: (command) => {
      switch (command.name) {
        case 'cart.addItem':
          return cartSlice.actions.addItem(command.payload);
        case 'cart.checkout':
          return cartSlice.actions.checkoutRequested();
      }
    },
  });
```

## How a release happens

1. Every pull request that changes a published package adds a changeset (`pnpm changeset`), per AGENTS.md rule 6.
2. When changesets reach `main`, the Release workflow opens or updates the "Version packages" pull request, which applies them: versions, changelogs, and internal dependency ranges.

The published packages are `@ironbird/core`, `@ironbird/react-native`, `@ironbird/cli`, `ironbird`, `@ironbird/testing`, `@ironbird/redux`, and `@ironbird/xstate`. `scripts/release/check-packs.mjs` packs each one and fails on a missing README or LICENSE, a missing ESM or CommonJS entry or declaration, shipped sources or tests, a `workspace:` range, an exact internal peer pin, or a `zod` peer other than `^4.2.0`. CI runs it on every commit; locally, `pnpm release:check` builds first. `--expect-version <version>` also checks every package's version and its internal dependencies.

## A package's first publish

A package that has never been published can't publish over OIDC: npm attaches a trusted publisher to an existing package, and one failed package stops `pnpm -r publish` before the packages after it, so the tags are never pushed. Before merging the Version packages pull request that introduces a package, publish its first version by hand from that pull request's branch, logged in to npm with 2FA:

npm trust github <package> --file release.yml --repo ironbird-dev/ironbird --allow-publish

- [ ] **Step 3: Implement the mode**

In `examples/checkout/eval/lib/isolation.mjs`, replace the doc comment and the whole `checkIsolation` function with:

```js
/**
 * Checks a session's init event. `memoryEntries` lists the auto-memory folder the event reports
 * (empty when the folder is absent or empty); `model` is the pattern the event's model id must match
 * (MODEL_PATTERN); `userSkills` are the user's skill names (userSkillNames). `ironbird` is
 * 'required' (M3: the ironbird MCP server connected and the ironbird skill loaded, and no other
 * server) or 'absent' (the M5 integration proxy, whose app has no ironbird yet: no MCP server at all
 * and no ironbird skill). Returns every problem, not only the first.
 */
export function checkIsolation(init, { memoryEntries, model, userSkills, ironbird = 'required' }) {
  assertPattern(model);
  if (!Array.isArray(userSkills)) throw new TypeError(`expected userSkills as an array of names, got ${JSON.stringify(userSkills)}`);
  if (ironbird !== 'required' && ironbird !== 'absent') throw new TypeError(`expected ironbird as 'required' or 'absent', got ${JSON.stringify(ironbird)}`);
  if (!init) return { valid: false, problems: ['the stream has no init event'] };
  const problems = [];

  const servers = Array.isArray(init.mcp_servers) ? init.mcp_servers : [];
  if (ironbird === 'required') {
    for (const name of names(servers)) if (name !== 'ironbird') problems.push(`MCP server ${name} is loaded`);
    const server = servers.find((candidate) => nameOf(candidate) === 'ironbird');
    if (!server) problems.push('the ironbird MCP server is not loaded');
    else if (typeof server !== 'object' || server.status !== 'connected') problems.push(`the ironbird MCP server is ${server.status ?? 'not reported as connected'}`);
  } else {
    for (const name of names(servers)) problems.push(`MCP server ${name} is loaded`);
  }

  const user = new Set(userSkills);
  const skills = names(init.skills);
  for (const skill of skills) {
    if (skill.includes(':')) problems.push(`skill ${skill} is loaded from a plugin`);
    else if (user.has(skill)) problems.push(`skill ${skill} is loaded, and the user skills folder has a skill of that name`);
  }
  if (ironbird === 'required' && !skills.includes('ironbird')) problems.push('the ironbird skill is not loaded');
  if (ironbird === 'absent' && skills.includes('ironbird')) problems.push('the ironbird skill is loaded');

  for (const plugin of Array.isArray(init.plugins) ? init.plugins : []) if (!isBuiltIn(plugin)) problems.push(`plugin ${JSON.stringify(plugin)} is not built in`);

  if (memoryEntries.length > 0) problems.push(`the auto-memory folder ${init.memory_paths?.auto} is not empty: ${memoryEntries.join(', ')}`);
  if (!runsOn(init.model, model)) problems.push(`the session runs on ${init.model}, not a model matching ${model}`);

  return { valid: problems.length === 0, problems };
}

Create `examples/bare-redux/eval/lib/contract.mjs`:

```js
// What the acceptance scenario asks of an integration (M5 design D11): the commands it sends, the
// fakes and controls it drives, the state paths it checks, and whether it advances the clock. TASK.md
// carries this as a generated block, so the task sheet and the scenario can't drift, and the grader's
// `commands` check uses its command names.

/**
 * The scenario in the wired example that exercise/acceptance.yaml (and so its generated copy in
 * integration-exercise/) copies byte for byte, relative to examples/bare-redux. Chosen in Task 7
 * Step 6 by the rule there.
 */
export const ACCEPTANCE_SOURCE = 'ironbird/scenarios/CHOSEN.yaml';

const byName = (a, b) => a.name.localeCompare(b.name);

/** The contract of a parsed scenario (`parseScenario` from @ironbird/cli/runner), sorted, with the first payload or condition seen for each entry. */
export function acceptanceContract(scenario) {
  const commands = new Map();
  const fakes = new Map();
  const paths = new Map();
  let clock = false;
  for (const step of scenario.steps) {
    if (step.kind === 'send' && !commands.has(step.command)) commands.set(step.command, step.payload);
    else if (step.kind === 'fake') {
      if (!fakes.has(step.fake)) fakes.set(step.fake, new Map());
      const controls = fakes.get(step.fake);
      if (!controls.has(step.control)) controls.set(step.control, step.payload);
    } else if ((step.kind === 'wait' || step.kind === 'expect') && !paths.has(step.path)) paths.set(step.path, step.condition);
    else if (step.kind === 'clock') clock = true;
  }
  return {
    commands: [...commands].map(([name, payload]) => ({ name, payload })).sort(byName),
    fakes: [...fakes]
      .map(([fake, controls]) => ({ fake, controls: [...controls].map(([name, payload]) => ({ name, payload })).sort(byName) }))
      .sort((a, b) => a.fake.localeCompare(b.fake)),
    paths: [...paths].map(([path, condition]) => ({ path, condition })).sort((a, b) => a.path.localeCompare(b.path)),
    clock,
  };
}

/** The command names the grader's `commands` check requires. */
export function commandNames(contract) {
  return contract.commands.map((command) => command.name);
}

const code = (value) => `\`${JSON.stringify(value).replaceAll('|', '\\|')}\``;

/** The contract as markdown: three tables (or "None.") and one sentence about the clock. Ends with a newline. */
export function renderContract(contract) {
  const lines = ['### Commands', ''];
  if (contract.commands.length === 0) lines.push('None.');
  else {
    lines.push('| Command | Payload in `acceptance.yaml` |', '|---|---|');
    for (const command of contract.commands) lines.push(`| \`${command.name}\` | ${code(command.payload)} |`);
  }
  lines.push('', '### Fakes', '');
  if (contract.fakes.length === 0) lines.push('None.');
  else {
    lines.push('| Fake | Control | Payload in `acceptance.yaml` |', '|---|---|---|');
    for (const fake of contract.fakes) for (const control of fake.controls) lines.push(`| \`${fake.fake}\` | \`${control.name}\` | ${code(control.payload)} |`);
  }
  lines.push('', '### State the scenario checks', '');
  if (contract.paths.length === 0) lines.push('None.');
  else {
    lines.push('| Path | Condition |', '|---|---|');
    for (const entry of contract.paths) lines.push(`| \`${entry.path}\` | ${code(entry.condition)} |`);
  }
  lines.push(
    '',
    contract.clock
      ? 'The scenario advances the clock, so the headless entry must schedule time through the `clock` that `defineHeadless` passes in, never through global timers.'
      : "The scenario doesn't advance the clock.",
    '',
  );
  return lines.join('\n');
}

export const CONTRACT_START = '<!-- contract:start (written by examples/bare-redux/eval/render-task.mjs from acceptance.yaml; do not edit by hand) -->';
export const CONTRACT_END = '<!-- contract:end -->';

/** The whole generated block, markers included. */
export function contractBlock(contract) {
  return `${CONTRACT_START}\n\n${renderContract(contract)}${CONTRACT_END}`;
}

/** `text` with everything from the start marker to the end marker replaced by `block`. */
export function replaceContractBlock(text, block) {
  const start = text.indexOf(CONTRACT_START);
  const end = text.indexOf(CONTRACT_END);
  if (start === -1 || end === -1 || end < start) throw new Error('TASK.md has no contract markers; restore the contract:start and contract:end lines');

}

/** The one JSON object `pnpm pack --json` prints, ignoring anything around it. */
export function packJson(stdout) {
  return JSON.parse(stdout.slice(stdout.indexOf('{'), stdout.lastIndexOf('}') + 1));
}

const SEMVER = /\d+\.\d+\.\d+(-[0-9A-Za-z.-]+)?/g;

/**
 * A packed manifest moved to `version`: its own version, every internal dependency and dev
 * dependency (which pnpm pack pins exactly), and the version inside every internal peer range
 * (`>=0.0.3` becomes `>=0.1.0`), as `changeset version` would leave them. Fields that are absent stay absent.
 */
export function releaseManifest(manifest, version, internal) {
  const exact = (deps) => Object.fromEntries(Object.entries(deps).map(([name, range]) => [name, internal.includes(name) ? version : range]));
  const ranged = (deps) => Object.fromEntries(Object.entries(deps).map(([name, range]) => [name, internal.includes(name) ? String(range).replace(SEMVER, version) : range]));
  const next = { ...manifest, version };
  if (manifest.dependencies) next.dependencies = exact(manifest.dependencies);
  if (manifest.devDependencies) next.devDependencies = exact(manifest.devDependencies);
  if (manifest.optionalDependencies) next.optionalDependencies = exact(manifest.optionalDependencies);
  if (manifest.peerDependencies) next.peerDependencies = ranged(manifest.peerDependencies);
  return next;
}

/** Problems with an npm lockfile after the TASK.md install: each vendored package once, from vendor/, at `version`. */
export function installProblems(lock, version) {
  const problems = [];
  const packages = lock.packages ?? {};
  for (const { name } of VENDORED) {
    const entry = packages[`node_modules/${name}`];
    if (!entry) {
      problems.push(`${name} is not installed`);
      continue;
    }
    if (entry.version !== version) problems.push(`${name} is ${entry.version}, not ${version}`);
    const file = `vendor/${tarballName(name, version)}`;
    if (!String(entry.resolved ?? '').includes(file)) problems.push(`${name} was not installed from ${file} (resolved: ${entry.resolved})`);
  }
  for (const key of Object.keys(packages)) {
    if (/node_modules\/@ironbird\/[^/]+\/node_modules\/@ironbird\//.test(key)) problems.push(`a second copy of an ironbird package is installed at ${key}`);
  }
  return problems;
}

// The published docs a proxy session gets (M5 design D11: "only the published docs"), and what it
// read of them. Published means what a developer finds on GitHub and npm: the README, each package's
// README, and docs/, without the design plans and specs under docs/superpowers/ and the eval records

export function isPublishedDoc(rel) {
  if (rel === 'README.md' || /^packages\/[^/]+\/README\.md$/.test(rel)) return true;
  return rel.startsWith('docs/') && rel.endsWith('.md') && !rel.startsWith('docs/superpowers/') && !rel.startsWith('docs/evals/');
}

/** The published docs among `relPaths` (git ls-files output, repository-relative), sorted. */
export function docsSet(relPaths) {
  return relPaths.filter(isPublishedDoc).sort();
}

const within = (file, root) => file === root || file.startsWith(root + path.sep);

/** The docs files the session read with Read, relative to the docs folder (any of `roots`), sorted and unique; and how many Grep or Glob calls searched in it. */
export function docsRead(calls, roots) {
  const read = new Set();
  let searches = 0;
  for (const call of calls) {
    const input = call.input ?? {};
    if (call.name === 'Read' && typeof input.file_path === 'string') {
      const root = roots.find((candidate) => within(input.file_path, candidate));
      if (root) read.add(path.relative(root, input.file_path).split(path.sep).join('/'));
    } else if ((call.name === 'Grep' || call.name === 'Glob') && typeof input.path === 'string' && roots.some((root) => within(input.path, root))) {
      searches += 1;
    }
  }
  return { read: [...read].sort(), searches };
}

/** Every line of `files` (`{ file, text }`) that contains `term`, trimmed to 160 characters. */
export function mentions(files, term) {
  const found = [];
  for (const { file, text } of files) {
    text.split('\n').forEach((line, index) => {
      if (line.includes(term)) found.push({ file, line: index + 1, excerpt: line.trim().slice(0, 160) });
    });
  }
  return found;
}

```js
// Which processes, ports, and paths belong to a proxy session. Unlike M3, the agent starts its own
// daemon (and may start Metro), and Claude Code's background Bash commands can leave its process
// group, so a process also counts as the session's when it works inside the session's project.
import os from 'node:os';

/** Pids whose working directory is one of `dirs` or inside it, from `lsof -d cwd -Fpn` output (`p<pid>`, `fcwd`, `n<path>` lines). Sorted, unique. */
export function pidsWithCwdUnder(lsofOutput, dirs) {
  const pids = new Set();
  let pid;
  for (const line of lsofOutput.split('\n')) {
    if (line.startsWith('p')) pid = Number(line.slice(1));
    else if (line.startsWith('n') && pid !== undefined) {
      const cwd = line.slice(1);
      if (dirs.some((dir) => cwd === dir || cwd.startsWith(`${dir}/`))) pids.add(pid);
    }
  }
  return [...pids].sort((a, b) => a - b);
}

/** Port listeners (`{ port, pid, pgid }`) split into the session's (a group the harness started, or a process working in the session) and anyone else's. */
export function classifyListeners(owners, { ownedGroups, sessionPids }) {
  const ours = [];
  const unknown = [];
  for (const owner of owners) (ownedGroups.includes(owner.pgid) || sessionPids.includes(owner.pid) ? ours : unknown).push(owner);
  return { ours, unknown };
}

/** Temporary folders: build tools write there, and naming one is not reaching for the repository or the eval home. */
export const TMP_ROOTS = [...new Set(['/tmp', '/private/tmp', '/var/folders', '/private/var/folders', os.tmpdir()])];

/** The out-of-folder hits (from outOfFolderPaths) that invalidate a session: everything outside the temporary folders. */
export function outsideProblems(hits, tmpRoots = TMP_ROOTS) {
  return hits.filter((hit) => !tmpRoots.some((root) => hit.path === root || hit.path.startsWith(`${root}/`)));
}

// The five checks of integration-exercise/CHECKLIST.md (M5 design D11), as pure judgments over what
// the grader observed. grade-project.mjs gathers the observations. Each returns { id, pass, detail };
// a missing or odd observation fails with a reason, never passes by default.

export const CHECKS = ['serve', 'commands', 'acceptance', 'bridgeDevOnly', 'releaseBundleClean'];

const verdict = (id, pass, detail) => ({ id, pass, detail });

/** 1. `ironbird serve` loads the headless entry: it started, and `ironbird status` lists `headless`. */
export function serveCheck({ error, status } = {}) {
  if (error) return verdict('serve', false, `ironbird serve did not start: ${error}`);
  const ids = (status?.targets ?? []).map((target) => target.id);
  if (ids.includes('headless')) return verdict('serve', true, 'ironbird serve loaded the headless entry; status lists the headless target');
  return verdict('serve', false, `ironbird status lists no headless target (targets: ${ids.join(', ') || 'none'})`);
}

/** 2. `ironbird commands` lists the declared commands: every command acceptance.yaml sends. */
export function commandsCheck({ listed, required, error }) {
  if (error) return verdict('commands', false, `ironbird commands failed: ${error}`);
  const names = Object.keys(listed ?? {});
  const missing = required.filter((name) => !names.includes(name));
  if (missing.length === 0) return verdict('commands', true, `lists ${names.length} commands, including every command acceptance.yaml sends: ${required.join(', ')}`);
  return verdict('commands', false, `missing ${missing.join(', ')} (listed: ${names.join(', ') || 'none'})`);
}

/** 3. The provided acceptance scenario passes headlessly: exit 0 and passed: true. */
export function acceptanceCheck(run) {
  if (!run) return verdict('acceptance', false, 'not run, because ironbird serve did not start');
  if (run.exitCode === 0 && run.result?.passed === true) return verdict('acceptance', true, `passed: ${run.result.stepsRun} steps in ${run.result.durationMs} ms`);
  if (run.result?.failedStep) return verdict('acceptance', false, `failed at step ${run.result.failedStep.index}: ${JSON.stringify(run.result.failedStep)}`);
  if (run.result) return verdict('acceptance', false, `exited ${run.exitCode} with passed: ${run.result.passed}`);
  return verdict('acceptance', false, `did not run: ${[run.error?.code, run.error?.message].filter(Boolean).join(' ') || `exit ${run.exitCode}`}`);
}

/** 4. The bridge is started under __DEV__ only, part one: the source calls startBridge, and a development bundle contains the bridge (verify-bundle exits 1). Part two is check 5. */
export function bridgeDevOnlyCheck({ callers, devBundle }) {
  if (callers.length === 0) return verdict('bridgeDevOnly', false, 'no source file outside node_modules imports startBridge from @ironbird/react-native and calls it');
  if (devBundle.error) return verdict('bridgeDevOnly', false, `the development bundle failed: ${devBundle.error}`);
  const { exitCode, report } = devBundle.scan;
  if (exitCode === 1 && (report?.found ?? []).length > 0) return verdict('bridgeDevOnly', true, `startBridge is called in ${callers.join(', ')}, and the development bundle contains the bridge`);
  if (exitCode === 0 && report) return verdict('bridgeDevOnly', false, 'the development bundle does not contain the bridge, so it is never started; check that the entry file reaches startBridge');
  return verdict('bridgeDevOnly', false, `verify-bundle exited ${exitCode} on the development bundle`);
}

/** 5. `verify-bundle` passes on a production bundle: exit 0, at least one file scanned, nothing found. */
export function releaseBundleCheck({ releaseBundle }) {
  if (releaseBundle.error) return verdict('releaseBundleClean', false, `the release bundle failed: ${releaseBundle.error}`);
  const { exitCode, report } = releaseBundle.scan;
  if (exitCode === 0 && report && report.scanned >= 1 && report.found.length === 0) return verdict('releaseBundleClean', true, 'the release bundle does not contain the bridge');
  if (exitCode === 0 && report) return verdict('releaseBundleClean', false, 'verify-bundle scanned nothing');
  if (exitCode === 1 && report) return verdict('releaseBundleClean', false, `the release bundle contains the bridge at ${report.found.map((hit) => `${hit.file}:${hit.offset}`).join(', ')}`);
  return verdict('releaseBundleClean', false, `verify-bundle exited ${exitCode} on the release bundle`);
}

/** The grade: passed only with all five checks present and passing. */
export function decide(checks) {
  const passing = checks.filter((check) => check.pass).length;
  const complete = CHECKS.every((id) => checks.some((check) => check.id === id));
  return { passed: complete && passing === CHECKS.length, score: `${passing}/${CHECKS.length}` };
}

// grade.mjs (a proxy session's copy, a human trial's folder, the selftest on the wired example) and
// by prepare.mjs (the un-integrated template, which must fail every check but the fifth).
//
// The project is graded where it is: the grader starts its own daemon there, on ports the OS picks,
// so it never meets another daemon, and writes .ironbird/ there; bundles and logs go under `out`.
import { cp, mkdir, mkdtemp, readFile, rm, writeFile } from 'node:fs/promises';
import os from 'node:os';
import path from 'node:path';
import { parseScenario } from '@ironbird/cli/runner';
import { ironbird, jsonLines, runScenarioFile, startServe } from '../../../checkout/eval/lib/ironbird.mjs';
import { run } from '../../../checkout/eval/lib/proc.mjs';

import { entryFile, isSourceFile, SOURCE_SKIP, startBridgeCallers } from './project.mjs';

const messageOf = (error) => (error instanceof Error ? error.message : String(error));
const tail = (text) => String(text ?? '').trim().slice(-1_500);

/** Builds one iOS bundle with the project's own react-native CLI and scans it with the project's own ironbird CLI. */
async function bundleAndScan(project, { dev, entry, out, env }) {
  if (!entry) return { error: 'no index.js, index.ts, index.tsx, or index.jsx at the top of the project' };
  const kind = dev ? 'dev' : 'release';
  const bundle = path.join(out, 'bundles', `${kind}.ios.js`);
  await mkdir(path.dirname(bundle), { recursive: true });
  const assets = await mkdtemp(path.join(os.tmpdir(), 'ironbird-proxy-assets-'));
  try {
    const args = ['bundle', '--platform', 'ios', '--dev', String(dev), '--minify', String(!dev), '--entry-file', entry, '--bundle-output', bundle, '--assets-dest', assets, '--reset-cache'];
    const built = await run(path.join(project, 'node_modules', '.bin', 'react-native'), args, { cwd: project, env, timeoutMs: 15 * 60_000 });
    await writeFile(path.join(out, 'logs', `bundle-${kind}.log`), `${built.stdout}\n${built.stderr}`);
    if (built.code !== 0) return { error: `react-native bundle --dev ${dev} exited ${built.code}: ${tail(built.stderr || built.stdout)}` };
    const scanned = await run(path.join(project, 'node_modules', '.bin', 'ironbird'), ['verify-bundle', bundle, '--json'], { cwd: project, env, timeoutMs: 120_000 });
    return { scan: { exitCode: scanned.code, report: jsonLines(scanned.stdout)[0] } };
  } catch (error) {
    return { error: messageOf(error) };
  } finally {
    await rm(assets, { recursive: true, force: true });
  }
}

/** The five checks on `project`, against the repository's `acceptance` scenario (copied into `out`, so the project's own copy is never used). */
export async function gradeProject({ project, acceptance, out, env = process.env }) {
  await mkdir(path.join(out, 'logs'), { recursive: true });
  const contract = acceptanceContract(parseScenario(await readFile(acceptance, 'utf8'), acceptance));
  const required = commandNames(contract);
  const checks = [];

  let serve;
  let serveError;
  let status;
  try {
    serve = await startServe(project, { env, logFile: path.join(out, 'logs', 'serve.log'), ephemeral: true, timeoutMs: 120_000 });
    status = (await ironbird(project, ['status'], { env, timeoutMs: 30_000 })).lines[0];
  } catch (error) {
    serveError = messageOf(error);
  }
  try {
    checks.push(serveCheck({ error: serveError, status }));
    if (serve && !serveError) {
      const listed = await ironbird(project, ['commands', '--target', 'headless'], { env, timeoutMs: 30_000 });
      const value = listed.lines[0];
      const error = listed.code === 0 ? undefined : (value?.error?.message ?? `exit ${listed.code}: ${tail(listed.stderr)}`);
      checks.push(commandsCheck({ listed: error ? undefined : value, required, error }));
      const copy = path.join(out, 'acceptance.yaml');
      await cp(acceptance, copy);
      checks.push(acceptanceCheck(await runScenarioFile(project, copy, 'headless', { env })));
    } else {
      checks.push(commandsCheck({ required, error: 'not run, because ironbird serve did not start' }));
      checks.push(acceptanceCheck(undefined));
    }
  } finally {
    await serve?.stop();
  }

  const files = await listFiles(project, SOURCE_SKIP);
  const sources = [];
  for (const file of files.filter(isSourceFile)) sources.push({ file, text: await readFile(path.join(project, file), 'utf8') });
  const entry = entryFile(files.filter((file) => !file.includes('/')));
  const devBundle = await bundleAndScan(project, { dev: true, entry, out, env });
  const releaseBundle = await bundleAndScan(project, { dev: false, entry, out, env });
  checks.push(bridgeDevOnlyCheck({ callers: startBridgeCallers(sources), devBundle }));
  checks.push(releaseBundleCheck({ releaseBundle }));
  return { checks, ...decide(checks), contract };
}

```js
#!/usr/bin/env node
// Runs one integration-proxy session (M5 design D11): a `claude -p` session on Sonnet, in the M3
// sandbox, that gets integration-exercise/TASK.md and only the published docs, outside the repository.
//
//   node examples/bare-redux/eval/run-session.mjs <id> [--label proxy|smoke] [--prompt <file>] [--max-budget-usd <n>] [--print-args]
//
// <id> names <eval home>/proxy/sessions/<id>/ and must be new. --print-args prints the command line,
// the settings, the sandbox profile, and the prompt, and starts nothing.
import { cp, mkdir, readdir, readFile, realpath, stat } from 'node:fs/promises';
import os from 'node:os';
import path from 'node:path';
import { parseArgs } from 'node:util';
import { claudeVersion, startClaude } from '../../checkout/eval/lib/claude.mjs';
import { renderSettings } from '../../checkout/eval/lib/claude-args.mjs';
import { checkIsolation, userSkillNames } from '../../checkout/eval/lib/isolation.mjs';
import { assertPortsFree, clone, groupAlive, listenerOwners, must, pgidOf, readJson, reapGroup, run, writeJson } from '../../checkout/eval/lib/proc.mjs';
import { sandboxProfile } from '../../checkout/eval/lib/sandbox.mjs';
import { sessionVerdict } from '../../checkout/eval/lib/session.mjs';
import { deniedCalls, outOfFolderPaths, parseTranscript, untrackedWrites } from '../../checkout/eval/lib/transcript.mjs';
import { fillPrompt, proxyArgs, proxyEnv } from './lib/args.mjs';
import { docsRead } from './lib/docs.mjs';
import { BUDGET_USD, evalDir, evalHome, MODEL, MODEL_PATTERN, PORTS, PROXY_SOURCES, proxyLayout, proxySessionLayout, repoRoot, sessionId, SESSION_LIMIT_MS, TEARDOWN_RESERVE_MS } from './lib/paths.mjs';
import { classifyListeners, outsideProblems, pidsWithCwdUnder } from './lib/session-rules.mjs';

const { values: options, positionals } = parseArgs({
  allowPositionals: true,
  options: { label: { type: 'string', default: 'proxy' }, prompt: { type: 'string' }, 'max-budget-usd': { type: 'string' }, 'print-args': { type: 'boolean' } },
});
const id = positionals[0];
const L = proxyLayout();
const budgetUsd = Number(options['max-budget-usd'] ?? BUDGET_USD);
const exists = (file) => stat(file).then(() => true, () => false);
const step = (message) => process.stderr.write(`run-session ${id}: ${message}\n`);
const errorText = (error) => (error instanceof Error ? error.message : String(error));

/** A path with its symlinks resolved, for a path that may not exist yet: the nearest existing ancestor is resolved and the rest appended. */
async function resolvedPath(dir) {
  const absolute = path.resolve(dir);
  const real = await realpath(absolute).catch(() => undefined);
  if (real) return real;
  const parent = path.dirname(absolute);
  return parent === absolute ? absolute : path.join(await resolvedPath(parent), path.basename(absolute));
}

/** Deny rules for the repository, the template, and every other folder that holds answers or other sessions. */
async function settingsFor() {
  const template = await readJson(path.join(evalDir, 'session-settings.json'));
  const sessions = (await readdir(L.sessions).catch(() => [])).filter((name) => name !== id).map((name) => path.join(L.sessions, name));
  return renderSettings(template, { repo: repoRoot, fixture: L.template, alsoDeny: [...sessions, L.grades, L.templateCheck, L.templateGrade, L.baselineDir, L.docs] });
}

/** Repository and eval home denied; the session's project and docs allowed again. */
async function profileFor(S) {
  return sandboxProfile({ denied: [await resolvedPath(repoRoot), await resolvedPath(evalHome())], allowed: [await resolvedPath(S.project), await resolvedPath(S.docs)] });
}

/** Why the prepared template can't be used now: a source changed since it was built, or (for a proxy session) it was built from uncommitted sources. */
async function staleness(label) {
  const prepared = await readJson(L.prepareFile).catch(() => null);
  const head = prepared?.repo?.head;
  if (typeof head !== 'string' || head === '') return ['prepare.json records no commit; run prepare.mjs again'];
  const problems = [];
  const diff = await run('git', ['diff', '--name-only', head, 'HEAD', '--', ...PROXY_SOURCES], { cwd: repoRoot });
  if (diff.code !== 0) problems.push(`cannot compare the prepared commit ${head.slice(0, 7)} with HEAD; run prepare.mjs again`);
  else {
    const changed = diff.stdout.split('\n').filter(Boolean);
    if (changed.length > 0) problems.push(`the template was prepared at ${head.slice(0, 7)} and ${changed.length} file(s) it is built from changed since: ${changed.join(', ')}; run prepare.mjs again`);
  }
  if (label === 'proxy' && (prepared.repo.dirty ?? []).length > 0) problems.push(`the template was prepared with uncommitted changes (${prepared.repo.dirty.join(', ')}); commit them and run prepare.mjs again`);
  return problems;
}

/** Runs claude until it exits, fails the isolation check, is interrupted, or reaches the deadline less the teardown reserve. */
async function runAgent({ S, args, env, prompt, profile, userSkills, record, deadline }) {
  let isolation;
  let checking;
  let timedOut = false;
  let giveUp;
  const gaveUp = new Promise((resolve) => {
    giveUp = resolve;
  });
  const stop = async (graceMs) => {
    await session.stop(graceMs);
    await new Promise((resolve) => setTimeout(resolve, 5_000).unref());
    giveUp({ code: null, signal: null, unresponsive: true });
  };
  const session = startClaude({
    cwd: S.project,
    args,
    env,
    prompt,
    profile,
    transcriptFile: S.transcript,
    stderrFile: S.stderr,
    onEvent: (event) => {
      if (checking || event.type !== 'system' || event.subtype !== 'init') return;
      record.resolvedModel = event.model ?? null;
      checking = (async () => {
        const memory = typeof event.memory_paths?.auto === 'string' ? await readdir(event.memory_paths.auto).catch(() => []) : [];
        isolation = checkIsolation(event, { memoryEntries: memory, model: MODEL_PATTERN, userSkills, ironbird: 'absent' });
        if (!isolation.valid) {
          step(`isolation check failed, stopping: ${isolation.problems.join('; ')}`);
          void stop(2_000);
        }
      })();
    },
  });
  record.claudeGroup = session.pgid;
  const stopOnSignal = () => {
    record.invalidReasons.push('interrupted by the operator');
    void stop(2_000);
  };
  process.once('SIGINT', stopOnSignal);
  process.once('SIGTERM', stopOnSignal);
  const limit = setTimeout(
    () => {
      timedOut = true;
      step('session deadline reached, stopping claude');
      void stop(10_000);
    },
    Math.max(0, deadline - TEARDOWN_RESERVE_MS - Date.now()),
  );
  const exit = await Promise.race([session.done, gaveUp]);
  clearTimeout(limit);
  process.off('SIGINT', stopOnSignal);
  process.off('SIGTERM', stopOnSignal);
  const reaped = await session.stop(2_000);
  await checking;
  isolation ??= checkIsolation(undefined, { memoryEntries: [], model: MODEL_PATTERN, userSkills, ironbird: 'absent' });
  return { exit, timedOut, isolation, reaped };
}

/**
 * Stops what the session left behind: every process working inside the project (the agent's daemon,
 * Metro, watchers, which may have left claude's group), then anything still on the ports. Returns the
 * groups still alive; a port held by a process that is not the session's makes the session invalid.
 */
async function teardown(record, roots, deadline) {
  const lsof = await run('lsof', ['-d', 'cwd', '-Fpn'], { timeoutMs: 30_000 });
  const sessionPids = pidsWithCwdUnder(lsof.stdout, roots).filter((pid) => pid !== process.pid);
  const groups = new Set();
  for (const pid of sessionPids) {
    const pgid = await pgidOf(pid).catch(() => undefined);
    if (pgid) groups.add(pgid);
  }
  groups.delete(await pgidOf(process.pid).catch(() => undefined));
  for (const pgid of groups) await reapGroup(pgid, { graceMs: 2_000, killMs: 2_000 });
  const owned = [record.claudeGroup, ...groups].filter((pgid) => pgid !== undefined);
  const until = Date.now() + Math.max(5_000, Math.min(30_000, deadline - Date.now()));
  for (;;) {
    const { ours, unknown } = classifyListeners(await listenerOwners(PORTS), { ownedGroups: owned, sessionPids });
    if (unknown.length > 0) {
      record.invalidReasons.push(`teardown: ${unknown.map((owner) => `port ${owner.port} is held by pid ${owner.pid}, which the session did not start`).join('; ')}`);
      break;
    }
    if (ours.length === 0) break;
    if (Date.now() > until) {
      record.invalidReasons.push(`teardown: ports still held by the session's processes: ${JSON.stringify(ours)}`);
      break;
    }
    for (const pgid of new Set(ours.map((owner) => owner.pgid))) await reapGroup(pgid, { graceMs: 2_000, killMs: 2_000 });
  }
  return owned.filter((pgid) => groupAlive(pgid)).map((pgid) => ({ name: pgid === record.claudeGroup ? 'claude' : 'session process', pgid }));
}

async function main() {
  if (!id) throw new Error('Pass a session id, such as proxy-1');
  const S = proxySessionLayout(L.home, sessionId(id));
  if (!['proxy', 'smoke'].includes(options.label)) throw new Error(`--label must be proxy or smoke, not ${options.label}`);
  if (!(budgetUsd > 0)) throw new Error(`--max-budget-usd must be a positive number, not ${options['max-budget-usd']}`);
  const promptFile = options.prompt ? path.resolve(options.prompt) : path.join(evalDir, 'prompt.md');
  const prompt = fillPrompt((await readFile(promptFile, 'utf8')).trim(), { docs: S.docs, repo: repoRoot });
  const settings = await settingsFor();
  const args = proxyArgs({ projectDir: S.project, docsDir: S.docs, settings, budgetUsd, model: MODEL });
  const profile = await profileFor(S);
  if (options['print-args']) {
    process.stdout.write(`${JSON.stringify({ cwd: S.project, command: 'sandbox-exec -p <profile> claude', args, settings, profile, prompt, stdin: 'prompt' }, null, 2)}\n`);
    return;
  }

  if (await exists(S.dir)) throw new Error(`${S.dir} exists; every session needs a new id`);
  if (!(await exists(path.join(L.template, 'package.json')))) throw new Error('No template; run prepare.mjs first');
  const baseline = await readJson(L.baselineFile).catch(() => {
    throw new Error('No baseline.json; run prepare.mjs without --skip-baseline first');
  });
  const version = await claudeVersion();
  if (version !== baseline.claudeVersion) throw new Error(`claude is ${version} but the baseline was recorded with ${baseline.claudeVersion}; run prepare.mjs again`);
  const stale = await staleness(options.label);
  if (stale.length > 0) throw new Error(`The template can't be used: ${stale.join('; ')}`);
  const head = (await must('git', ['rev-parse', 'HEAD'], { cwd: repoRoot })).stdout.trim();
  const userSkills = await userSkillNames();
  await assertPortsFree(PORTS);

  const startedAt = Date.now();
  const deadline = startedAt + SESSION_LIMIT_MS;
  await mkdir(S.logs, { recursive: true });
  const record = {
    session: id,
    label: options.label,
    startedAt: new Date(startedAt).toISOString(),
    deadline: new Date(deadline).toISOString(),
    head,
    claudeVersion: version,
    model: MODEL,
    resolvedModel: null,
    budgetUsd,
    limitMinutes: SESSION_LIMIT_MS / 60_000,
    prompt,
    sandboxProfile: profile,
    userSkills,
    invalidReasons: [],
  };
  const env = proxyEnv(process.env);
  let aliveGroups = [];
  try {
    step(`cloning the template into ${S.project}, copying the docs to ${S.docs}`);
    await clone(L.template, S.project, { timeoutMs: 120_000 });
    await cp(L.docs, S.docs, { recursive: true });
    await must('chmod', ['-R', 'a-w', S.docs]);
    await writeJson(S.settings, settings);
    step('starting claude in the sandbox');
    const agent = await runAgent({ S, args, env, prompt, profile, userSkills, record, deadline });
    record.exit = agent.exit;
    record.timedOut = agent.timedOut;
    record.isolation = agent.isolation;
    record.reapedClaude = agent.reaped;
  } catch (error) {
    record.invalidReasons.push(`startup: ${errorText(error)}`);
  } finally {
    const roots = [S.project, await realpath(S.project).catch(() => S.project)];
    const docsRoots = [S.docs, await realpath(S.docs).catch(() => S.docs)];
    try {
      aliveGroups = await teardown(record, roots, deadline);
    } catch (error) {
      record.invalidReasons.push(`teardown: ${errorText(error)}`);
    }
    if (await exists(S.transcript)) {
      const parsed = parseTranscript(await readFile(S.transcript, 'utf8'));
      record.result = parsed.result
        ? { subtype: parsed.result.subtype, isError: parsed.result.is_error, costUsd: parsed.result.total_cost_usd, durationMs: parsed.result.duration_ms, numTurns: parsed.result.num_turns }
        : null;
      record.deniedToolCalls = deniedCalls(parsed);
      record.outOfFolderPaths = outOfFolderPaths(parsed.calls, [...roots, ...docsRoots], os.homedir());
      const invalidating = outsideProblems(record.outOfFolderPaths);
      if (invalidating.length > 0) record.invalidReasons.push(`outside-folder access: ${invalidating.map((hit) => `${hit.tool} ${hit.path}`).join('; ')}`);
      record.untrackedWrites = untrackedWrites(parsed.calls).map((call) => ({ index: call.index, command: call.input.command }));
      record.docsRead = docsRead(parsed.calls, docsRoots);
    }
    const finishedAt = Date.now();
    const verdict = sessionVerdict({ reasons: record.invalidReasons, isolation: record.isolation, deadline, finishedAt, aliveGroups });
    record.finishedAt = new Date(finishedAt).toISOString();
    record.aliveGroups = aliveGroups;
    record.invalidReasons = verdict.invalidReasons;
    record.valid = verdict.valid;
    await writeJson(S.record, record);
    process.stdout.write(`${JSON.stringify({ session: id, label: record.label, valid: record.valid, invalidReasons: record.invalidReasons, timedOut: record.timedOut ?? false, model: record.resolvedModel, result: record.result ?? null, deniedToolCalls: record.deniedToolCalls ?? null, docsRead: record.docsRead?.read.length ?? null })}\n`);
  }
}

main().catch((error) => {
  process.stderr.write(`run-session failed: ${error instanceof Error ? error.message : String(error)}\n`);
  process.exitCode = 1;
});

# The M5 integration proxy

This folder measures a **proxy** for the first M5 exit criterion in [docs/roadmap.md](../../../docs/roadmap.md): "a developer other than the author wires ironbird into a copy of `examples/bare-redux` that doesn't include it yet, using only the docs, in ≤ 1 day". That criterion needs a human and is the maintainer's go/no-go for releasing 0.1.0; the proxy never ticks it. The design is D11 and §1 of [the M5 design](../../../docs/superpowers/specs/2026-10-04-m5-adapters-and-0.1-design.md); results go in [docs/evals/m5-adapters-and-0.1.md](../../../docs/evals/m5-adapters-and-0.1.md).

The proxy is one `claude -p` session on Sonnet that gets the same task sheet as the human, `integration-exercise/TASK.md`, and only the published docs, outside the repository and inside the M3 eval's sandbox. A grader scores the result on the five checks of `integration-exercise/CHECKLIST.md`, the same checks a human scorer runs. It runs by hand on macOS and never in CI; its unit tests (`lib/*.test.mjs`) run in `pnpm test` and never start `claude`.

## Before you start

- macOS, Node 22 or later, pnpm, npm, git, and Claude Code installed and signed in.
- Ports 4567, 4568, and 8081 free: no `ironbird serve` and no Metro running.
- No `AGENTS.md` or `CLAUDE.md` in `~/.ironbird-eval` or any folder above it. `prepare.mjs` checks this.

## Commands

All of them run from the repository root.

| Command | What it does |
|---|---|
| `node examples/bare-redux/eval/prepare.mjs` | Builds the packages; copies `integration-exercise/` to `~/.ironbird-eval/proxy/template/` without dependencies or build output, checking that it stands alone and names ironbird only in its four material files; packs core, react-native, redux, and cli and repacks them at 0.1.0 into `vendor/`; installs the app's own dependencies; commits it all as one git commit; copies the published docs (the README, package READMEs, and `docs/` without `docs/superpowers/` and `docs/evals/`) to `proxy/docs/`; checks, on a clone, that TASK.md's install commands install each tarball once from `vendor/` and that the grader fails the untouched app on every check but the fifth; and records a baseline from one `claude` start in an empty folder. `--skip-build` reuses `dist/`; `--skip-baseline` skips the `claude` start |

## Valid and graded

A session is invalid, and not graded as a result, when the setup failed, its init event fails the isolation check (any MCP server, the ironbird skill, a plugin that isn't built in, a user or plugin-namespaced skill, non-empty auto-memory, or a model not matching `^claude-sonnet-`), a tool call named a path outside its project and docs other than a temporary folder, a port was held by a process it didn't start, a process group outlived the bounded reap, the 90-minute deadline passed before teardown finished, or the operator interrupted it. Its time or budget running out does not make it invalid.

The grader runs the five checks on a copy of the project, with the repository's `acceptance.yaml` rather than the session's: `serve`, `commands`, `acceptance`, `bridgeDevOnly`, `releaseBundleClean`, as CHECKLIST.md describes. It starts its own daemon on ports the OS picks and bundles with the project's own `react-native` CLI. The session succeeds when all five pass.
